Keyboard

Every shortcut Mindle binds, grouped by menu.

File

⌘NNew window
⌘OOpen…
⌘⇧LOpen URL…
⌘⇧VOpen from Clipboard
⌘⇧EExport Annotations…
⌘WClose active tab (or window when only one tab is open)
⌘PExport as PDF…

Edit

⌘⇧HHighlight Selection
⌘⇧NAdd Note to Selection…
⌘⇧KAdd Comment to Selection
⌘EEdit Document… (Markdown only)
⌘⌥⏎Keep All Changes (diff overlay)
⌘⌥⌫Revert All Changes (diff overlay)

Find

⌘FFind…
⌘GFind Next
⌘⇧GFind Previous

View

⌘⇧FToggle Files sidebar
⌘⇧AToggle Annotations sidebar
⌘+Increase Font Size
⌘-Decrease Font Size
⌘⇧TCycle Theme (light / sepia / dark)
⌘1Reading Width — Narrow
⌘2Reading Width — Medium
⌘3Reading Width — Wide
⌘0Fit Width (PDF only — reset zoom)
⌘⇧DToggle Debug Console (annotation lifecycle events)

In an annotation editor

ReturnCommit the note or reply
⇧ReturnInsert a newline

In the document editor

⌘ReturnSave
EscCancel
