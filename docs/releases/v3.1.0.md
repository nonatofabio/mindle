# Mindle v3.1.0

The first stable cut of the v3 line. It folds the entire v3.0 and v3.1 release-candidate train into one signed, notarized release — PDF reading, an in-place editor, files that live on another machine, the agent-collaboration polish, a default font-size setting, and a refreshed site. If you've been on the beta channel you watched these land one at a time; here they are together, on the stable channel, for everyone.

## Read PDFs, not just Markdown

The big one from the v3.0 train: Mindle opens text-based PDFs through PDFKit and treats them as first-class reader tabs. Highlights and notes work exactly as they do on Markdown — same annotation model, same local sidecar, same agent-readable channel over MCP. Nothing about a PDF changes how you mark it up or how an agent reads your notes back.

## `⌘E` — fix a thing in place

The recurring "let me fix this typo without switching to vim" request gets a quiet answer. **⌘E on any local Markdown file** swaps the reader for a full-document editor — bare source in a monospace font, three buttons: **Save** (`⌘Return`), **Preview**, **Cancel** (Esc). It's deliberately the smallest surface that lets you edit in place; Mindle still isn't trying to be a Markdown editor.

It also won't let you clobber someone else's write. The editor hashes the file when you open it and checks again on Save — if an agent, a `git pull`, or another app changed the file underneath you, you get a three-way choice (keep yours, take theirs, or keep editing to merge by hand) instead of a silent overwrite.

## Open files that live on another machine

If the Markdown you care about sits on a remote dev box, it's now one shortcut away. **File ▸ Open Remote…** (`⌘⇧O`) takes an SSH target — `user@host:/path/notes.md` — and Mindle fetches, renders, annotates, edits, and writes back. It uses **your** SSH: it shells out to the `ssh`/`scp` already on your Mac, so `~/.ssh/config`, agent keys, `known_hosts`, and ProxyJump all apply, and Mindle never sees a credential. Saves push back atomically (temp-then-rename), so a dropped connection can't truncate the far-side file; the local copy stays authoritative. Power users can `open 'mindle://ssh/user@host/path'`, and the MCP `open_file` tool accepts remote targets too.

Remote tabs are manual-refresh (a ↻ button, no background polling) and their annotations are local-only for now — both are documented limits, not surprises.

## A default font size

New in this cut: **Settings (`⌘,`)** with a slider for the font scale new documents open at, persisted alongside your reading width and font. Per-document overrides still win — set a doc bigger or smaller and that sticks in its sidecar; the default only governs what a *fresh* doc starts at, and changing it never reflows documents you already have open. The toolbar `A`/`A` buttons, the `⌘+`/`⌘-` shortcuts, and the slider all index the same fixed step table, so the size you pick is the size you get.

## Notes

- **Auto-update:** this is a stable release — it ships to everyone, no pre-release flag required. (Beta-channel users on rc5 land here too.)
- **Signed & notarized:** the DMG is Developer ID-signed and notarized, so it opens cleanly on any Mac with no Gatekeeper detour.
- **Still local-first, still no network calls** beyond the SSH you explicitly point it at and the update check.
