# Mindle v3.2.1

This release fixes a security issue in how Mindle handles HTML inside Markdown. Updating is recommended, especially if you open documents from other people or remote sources.

Crafted document HTML could execute JavaScript in the reader and reach native document-writing actions. Mindle now sanitizes HTML before rendering it, blocks automatic network loads and embedded pages, and accepts native bridge messages only from the bundled reader's main frame. The shared rendering protections also apply to Quick Look previews.

Normal Markdown and safe HTML formatting still work, including tables, task lists, local images, math, diagrams, annotations, search, and diff controls. Document scripts, custom stylesheets, forms, and embedded pages are no longer supported.

The fix includes WKWebView regression tests for malicious document content, network restrictions, navigation, and native bridge access. These run alongside the existing logic tests in CI before the app can be released.

No document or annotation migration is needed.
