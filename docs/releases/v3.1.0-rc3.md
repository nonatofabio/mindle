## What's new

### Agent identifier on annotations, replies, and reactions

Two agents working in the same document used to be indistinguishable in the sidebar — every MCP-authored card said *Agent* and that was it. `mindle-mcp` now captures the MCP client's display name from `clientInfo` on the `initialize` handshake (e.g. `Claude Code` → `claude-code`), normalises it to a short slug, and threads it as an `agent_tag` field on every write. The Mindle sidebar renders the tag as a small monospace chip next to the author label on annotation cards, reply rows, and reactions — so the reader can tell `claude-code` from `cursor` at a glance.

Closes [#33](https://github.com/nonatofabio/mindle/issues/33).

Backward-compatible: older `mindle-mcp` helpers that never sent the field still work — the chip is just omitted and the annotation appears as a generic `agent`.

### New MCP write: `open_file`

A new tool agents can call to bring a file into Mindle without the user having to open it first.

```
open_file(path: String, focus_app?: Boolean = false)
```

If any window already has the file open, the existing tab is activated; otherwise a new tab opens in the most-recently-active window. `focus_app` defaults to **false** — the file opens silently in the background so an agent prepping a working set doesn't steal the user's focus. Pass `true` when the agent specifically wants the user to look at the file now.

Closes [#34](https://github.com/nonatofabio/mindle/issues/34).

Use cases this unblocks: an agent walking through a directory of notes, opening each as it reads them; an agent that needs to leave annotations on a file the user hasn't opened yet; an agent assistant pulling up references during a conversation.

### `#31` closed — fixed-incidentally in rc2

The bug "agent-created annotations don't get a body highlight" was already fixed in v3.1.0-rc2 by the `#32` patch (rebuild the per-iteration text map before each annotation paint). Both bugs traced to the same overlay-injection pipeline — agent-created and user-created annotations land in the same array and run through the same paint code. Closed retroactively.
